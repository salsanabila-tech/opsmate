# Mobile Foundation

## Stack

- React Native
- Expo
- TypeScript
- Expo Router

## Environment

Mobile API URL menggunakan:

EXPO_PUBLIC_API_URL

Local physical device menggunakan LAN IP development machine.

## API Connectivity

Endpoint:

GET /api/health

Expected:

200 OK

OpsMate API is running

## Verification

- Expo project berhasil dibuat
- TypeScript berjalan
- Expo Router berjalan
- Environment API berhasil dibaca
- Backend dapat diakses melalui LAN
- Mobile berhasil memanggil GET /api/health
- Typecheck berhasil
- Expo Doctor berhasil
