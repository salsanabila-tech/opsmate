# Mobile Admin Work Order List

## Summary

Menambahkan dashboard dan daftar seluruh
Work Order untuk ADMIN pada mobile OpsMate.

## Endpoint

GET /api/work-orders

## Features

- Admin dashboard
- Total Work Order
- Work Order list
- Search
- Status filter
- Pull to refresh
- Pagination
- Loading state
- Empty state
- Error state
- Customer information
- Technician information
- Scheduled date
- Logout

## Authorization

ADMIN only.
